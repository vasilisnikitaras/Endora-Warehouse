## 📦✨ Endora Warehouse

Welcome to **Endora Warehouse**, a sleek, browser-based warehouse management system designed and developed by Vasilis Nikitaras. It’s part of the growing **VasiVerse** ecosystem, now live at:

🌐 [vasiverse.com](https://vasiverse.com)  
🌐 [vasifanesapp.com](https://vasifanesapp.com)

---

### 🚀 Features

- 🔐 **User Authentication** – Register and log in securely  
- 📊 **Inventory Management** – Add, edit, and view warehouse items  
- 🎨 **Responsive UI** – Clean, intuitive design  
- 🌐 **Client-Side Only** – Runs entirely in the browser  

---

### 🛠️ Tech Stack

- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript** – Logic and interactivity  
- **JSON** – Local data storage
