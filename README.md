### 🚀 Features

- 🔐 **User Authentication** – Register and log in securely  
- 📊 **Inventory Management** – Add, edit, and view warehouse items  
- 🎨 **Responsive UI** – Clean, intuitive design  
- 🌐 **Client-Side Only** – Runs entirely in the browser
